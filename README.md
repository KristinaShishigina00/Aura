# АИС «Аура»

**Дипломный проект · Информационная система персонализированного подбора косметических продуктов**

«Аура» — проект информационной системы, в котором я связала анализ предметной области, требования к продукту, пользовательские сценарии и техническое проектирование.

## Задача проекта

Подбор косметических продуктов требует учитывать индивидуальные особенности и потребности пользователя. В проекте проработана система персонализированного подбора, которая связывает пользовательский профиль, данные о продуктах и логику рекомендаций.

## Мой вклад как аналитика

- Исследовала предметную область и определила требования к системе.
- Описала пользовательские и бизнес-процессы.
- Спроектировала модели данных.
- Проработала логику персонализированных рекомендаций.
- Связала аналитическую часть с техническим решением на основе PostgreSQL, REST API и RAG-компонента с векторным поиском.
